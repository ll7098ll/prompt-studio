# 모션 편집 구현 기록

2026-10-07. 확장 계획의 추가 모션 12후보 중 7종과 공통 재생 제어, 내부 부분별 독립 모션을 구현했다. 기존 12효과를 포함해 효과 선택은 19종이며 `none`은 별도다. 부분 목록에는 실제 대상과 호환되는 효과를 제공한다. 최종 검사·배포 결과는 [실행 기록](EXPANSION_EXECUTION.md)을 따른다.

## 저장과 편집

- 문서 v5의 선택 속성 `appearance.motionSettings`에 시간·지연·반복·강도·속도 곡선·시작 조건·모바일 정지·단어 간격·화면 진입 비율/한 번 실행·스크롤 범위를 저장한다. 없는 필드를 기존 문서에 주입하지 않는다. 범위/유한 숫자/알 수 없는 필드는 스키마로 검증한다.
- 지정한 값 → 상속된 테마 값 → 효과 기본값 순서다. 기존 효과의 시간·반복 기본값, 작성 불투명도, 명시적 `none`을 보존한다. 여러 요소 선택의 혼합값, 값별 출처·복원, Undo/Redo·저장/다시 열기를 지원한다.
- 페이드·마스크 계열은 강도 1에서 완전히 가린다. 이동/크기 계열은 2까지 확대한다. 스크롤 구간은 화면 아래 진입 0%, 위로 완전히 이탈 100%를 기준으로 한다. 스크롤 재생은 반복 횟수와 무관하게 한 주기를 탐색한다.
- 전체/선택한 요소와 하위 요소에 재생·정지·처음부터·진행 탐색을 제공한다. 진행 표시는 첫 재생 가능 요소의 한 주기이며 시간 길이가 다른 요소들의 통합 타임라인은 아니다. 탐색은 해당 범위를 정지하고, 재생은 시작 조건/스크롤에 다시 연결한다. 처음부터는 선택한 효과를 설정된 반복 횟수로 수동 시작한다(스크롤 효과는 한 주기).

## 렌더링과 복원

- 새 `words`, `mask`, `parallax`, `scroll-zoom`은 `motion/mini`를 실제 재생이 필요할 때 가져와 내부 콘텐츠에 적용한다. 바깥 위치/회전/크기 transform을 바꾸지 않는다. 컨테이너는 하위 leaf 콘텐츠를 동기화하며 자체 효과가 있는 하위 요소는 자기 효과가 우선한다. 하나의 평면으로 합성해 컨테이너 전체를 확대하는 기능은 아니다.
- 단어 분리는 고정 제목·본문·인용에만 적용한다. 버튼·입력·실시간 숫자·SVG·미디어·숨겨진 텍스트는 제외한다. 공백/줄바꿈과 원본 Text 객체를 복원하고, 기존 부분 경로는 원래 DOM 대상에 고정해 임시 span 때문에 다른 부분이 수정되지 않게 한다.
- 기존 CSS 효과는 이름과 렌더링 구조를 유지하는 어댑터를 사용한다. Web Animations API로 재생/정지/탐색하고 CSS 변수로 설정값을 적용한다. 기존 효과 전체를 내부 래퍼로 이관한 것은 아니다. lift/tilt는 포커스/호버 진입과 복귀를 제어 가능한 애니메이션으로 연결했다.
- 요소가 속한 iframe의 문서/윈도우로 스크롤·IntersectionObserver·움직임 감소·모바일·visibilitychange를 처리한다. Motion의 호스트 `EventTarget` 검사에 걸리지 않도록 iframe 요소를 배열로 전달한다. 실제 iframe 브라우저 검사로 실행을 확인한다.
- 화면 밖/백그라운드에서는 정지하고, 움직임 감소·모바일 정지는 원래 정지 콘텐츠를 표시한다. 편집·PNG·분해 측정·LiveThumbnail은 런타임을 실행하지 않는다. 애니메이션 완료 때 라이브러리가 쓴 inline style, 임시 텍스트, tabindex, 이벤트·관찰자·타이머를 해제한다. 입력/버튼 등에 포커스가 들어오면 가림/등장 효과를 완료 상태로 정지해 조작 대상을 보인다.
- 미리보기 작업 영역은 화면에 맞는 높이를 사용해 하단 제어를 누를 수 있게 했다. 크기가 콘텐츠에 따라 정해지는 모달에는 이 계산을 적용하지 않아 높이가 계속 줄어드는 피드백을 막았다.

## 전달과 의존성

AI 전달의 `resolvedMotions`와 `resolvedPartMotions[nodeId][path]`에는 효과·실제 값·엔진·대상·정지 규칙을 담는다. 새 효과와 부분 모션은 CSS만으로 재현되지 않는다는 점과 동작 요구를 명시했다. JSON/ZIP/공유는 같은 원본 설정을 보존한다.

Motion 14.0.0을 lockfile로 설치했다. [공식 animate 문서](https://motion.dev/docs/animate), [scroll 문서](https://motion.dev/docs/scroll), 설치된 DOM resolver/NativeAnimation 코드를 참고했다. 사이트의 `motion-license.txt`에 Motion과 Framer의 MIT 저작권/허가문을 포함한다. 편집과 정지 화면에서는 mini 엔진을 가져오지 않는다. 라이브러리 안내의 번들 크기를 앱의 실측 크기로 표기하지 않는다.

`scripts/measure-motion.ts`는 다른 브라우저 검사 없이 정적 서버에서 실행한다. 네 효과를 동시에 반복하는 장면과 정지 기준 장면을 각각 120 프레임 측정하고 브라우저·CPU·메모리·실제 뷰포트와 p50/p95/최대를 `artifacts/motion-frames-*.json`에 저장한다. 60Hz의 p95 20ms는 초기 목표이며 측정 환경과 함께 해석한다. 실기기 iOS/Android 측정을 대신하지 않는다.

## 남은 범위

추가 5모션(숫자 카운트·배경 교차·카드 쌓임·상태/장면 전환), 시작/종료 값 직접 편집, 이름 있는 상태/상태 간 전환, 화면별 상세 오버라이드, 대표 시점 저장, 공통 인스턴스·시퀀스 타임라인, Lottie/Rive/3D 런타임은 별도 후속 단계다. 원래 16팩/20신규 기능/24장면 목표를 줄이거나 완료로 표시하지 않는다.

## 내부 부분과 포인터·SVG 효과

- `parts[path].motion = {preset, settings?}`는 선택 속성이다. 기본값은 효과 없음이며 테마나 바깥 노드 효과를 상속하지 않는다. 부분마다 효과·시간·강도·시작 조건·반복·스크롤 범위를 수정하고 값별 복원과 Undo/저장/공유를 지원한다. 기존 외형 초기화는 모션을 보존한다. 항목 복제는 stable slot 경로와 Part 전체를 함께 복사한다.
- 부모가 다른 DOM 요소이면 시각적 효과가 합성된다. 같은 요소를 대상으로 하는 내부 콘텐츠 효과는 명시적 부분 트랙이 우선한다. 사용할 대상이 남지 않은 상위 트랙은 no-target으로 표시하며 중복 translate 애니메이션을 등록하지 않는다. `none`은 해당 부분 자신의 트랙만 끈다.
- fade/pulse는 filter:opacity, glow는 filter:drop-shadow로 원래 불투명도와 그림자를 보존한다. 이동/회전/크기는 개별 translate/rotate/scale을 사용한다. SVG는 fill-box 중심을 사용한다. 변형할 수 없는 inline 부분은 재생 동안 inline-block으로 만들고 편집 복귀 시 원래 display와 우선순위를 복원한다.
- draw는 실제 stroke가 있는 SVGGeometryElement에만 제공한다. getTotalLength 또는 작성한 pathLength의 단위로 dash 길이를 계산하며 fill/stroke/strokeWidth를 변경하지 않는다. 적합하지 않은 저장 효과는 삭제하지 않고 no-target과 안내를 제공한다.
- magnetic은 안정된 선택/호버 영역 바로 아래 콘텐츠를 ±16px × 강도 안에서 이동시킨다. 독립 부분 모션이 있는 같은 자식은 제외한다. spotlight는 별도 aria-hidden/pointer-events:none fixed 오버레이의 radial-gradient 중심을 포인터에 맞춘다. 원래 래퍼·absolute 기준·부분 경로를 바꾸지 않는다. 시간과 easing은 반응 속도이며 반복/지연/다른 시작 조건은 제공하지 않는다. 키보드 포커스는 중앙 효과, 768px 미만·coarse pointer·움직임 감소는 정지 상태다.
- 소유 문서의 MutationObserver로 새 부분만 등록하고 사라진 부분만 해제한다. 팝업을 다시 열 때 다른 트랙의 Animation 객체/시간은 유지한다. 전체/선택 범위의 정지·재생·탐색 정책은 나중에 열린 부분에도 적용한다. 네이티브 버튼과 Radix role 위젯의 Enter/Space 기본 동작을 보존하며 aria-hidden/inert 부분에 새 Tab 정지를 만들지 않는다.
- 단어용 경로 고정은 노드별 참조 수를 공유한다. 명시적 자식 부분은 상위 단어 분리에서 제외하고 원본 Text/inline 스타일/이벤트/관찰자/오버레이를 해제한다.

빌드는 플랫폼에서 발생한 Turbopack PostCSS 프로세스 오류를 피해 설치된 Next.js 문서의 `next build --webpack` 경로를 사용한다. 사용하지 않던 next/font Google 다운로드를 제거하고 앱 기본 서체를 기존 Arial/system 및 monospace 스택으로 지정했다. 설계의 테마 서체와 업로드 서체 자산은 기존 파이프라인을 따른다.
