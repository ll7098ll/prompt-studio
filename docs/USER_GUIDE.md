# 사용 가이드

## 1. 프리셋에서 시작

작업 공간에는 브랜드·소개, 앱·데이터, 스토어·콘텐츠 프리셋이 있습니다. 카드의 실제 화면을 보고 고른 뒤 **크게 보기**에서 데스크톱·태블릿·모바일을 확인합니다. 선택하면 편집 가능한 프로젝트가 만들어집니다.

빈 페이지로 시작할 수도 있습니다. 프리셋은 이미지 한 장을 편집하는 방식이 아니라 내부 요소와 배치가 있는 설계입니다.

## 2. 요소 추가와 배치

컴포넌트 목록에서 그림, 쉬운 이름, 짧은 설명으로 요소를 찾습니다. **크게 보기**에서 선택한 프로젝트 테마로 실제 동작을 체험하고 추가합니다.

| 원하는 화면             | 사용할 요소 예                          |
| ----------------------- | --------------------------------------- |
| 소개 페이지 첫 화면     | 첫 화면 소개, 제목, 버튼, 이미지        |
| 카드가 나란히 있는 영역 | 여러 칸에 배치, 카드, 기능 소개         |
| 설정 화면               | 입력창, 선택 메뉴, 켜기·끄기, 체크박스  |
| 데이터 화면             | 숫자 요약, 데이터 표, 막대·비율 차트    |
| 안내와 피드백           | 팝업, 알림, 안내 메시지, 내용이 없을 때 |

캔버스에서 선택한 요소는 속성 패널에서 문구·값·배치를 수정할 수 있습니다. 레이어 드래그나 부모·순서 설정으로 중첩 구조를 바꿉니다. 복제·삭제·숨김·잠금과 실행 취소·다시 실행을 사용할 수 있습니다.

## 3. 레이아웃과 반응형

가로·세로 방향, 줄바꿈, 정렬, 간격, 안팎 여백, 너비, 최소 높이와 Grid 열 점유를 조절합니다. 기본 레이아웃 위에 태블릿·데스크톱 변경값을 적용합니다.

- 모바일 기준 폭: 390px
- 태블릿 기준 폭: 768px
- 데스크톱 기준 폭: 1440px
- 직접 입력: 320~2560px

768px부터 태블릿, 1024px부터 데스크톱 규칙이 적용됩니다. 1440px 화면을 50%로 축소해서 봐도 레이아웃은 1440px 기준입니다. 확대 배율과 화면 폭은 서로 다릅니다.

## 4. 테마 바꾸기

12개 테마 중 하나를 고르고 라이트·다크 모드의 색상, 서체 계열, 모서리, 밀도를 조정합니다. 테마는 프로젝트 전체에 적용됩니다.

다른 프리셋을 기존 프로젝트의 새 페이지로 추가하면 현재 프로젝트의 테마를 유지합니다. 프리셋별 원래 테마를 비교하려면 별도 프로젝트로 여세요.

## 5. 동작 확인

편집 모드에서는 요소 선택이 우선입니다. 미리보기에서 탭 전환, 표 정렬, 검색, 달력 날짜 선택, 팝업, 입력 등을 확인합니다.

채팅은 예시 응답을 보여주고 문의·구독 폼은 예시 완료 상태를 보여줍니다. 실제 메시지·이메일 전송, 인증, 결제, 서버 데이터 저장은 실행되지 않습니다. AI에게 실제 앱을 구현시킬 때 필요한 연결을 추가로 설명하세요.

## 6. 저장·백업·복구

수정 내용은 현재 브라우저에 자동 저장됩니다. 프로젝트 JSON 파일을 별도로 다운로드하면 다른 브라우저에서 가져올 수 있습니다.

- 버전 보관은 프로젝트당 최대 20개입니다.
- 실행 취소 기록은 편집 세션의 최근 최대 60개이며 연속 입력은 묶일 수 있습니다.
- 두 탭이 같은 프로젝트를 수정하면 충돌을 안내합니다. 사본으로 저장하거나 JSON으로 백업하세요.
- 저장하지 못한 작업은 작업 공간의 **복구 자료**에서 확인하고 사본으로 복원할 수 있습니다.
- 저장소 오류가 계속되면 현재 작업을 JSON으로 다운로드한 뒤 문제를 확인하세요.

브라우저 데이터를 지우기 전에 먼저 백업하세요. 사이트를 다른 도메인으로 옮겨도 프로젝트는 자동 이동하지 않습니다.

## 7. 공유와 AI 전달

공유 링크는 만든 시점의 읽기 전용 설계 사본입니다. 받은 사람은 자신의 브라우저에 사본을 저장해 수정할 수 있습니다. 이후 원본을 수정해도 이전 링크는 갱신되지 않습니다. 긴 설계는 URL 대신 JSON으로 전달합니다.

**AI에 전달**에서 프롬프트를 복사하거나 PNG·ZIP을 다운로드합니다. ZIP의 `START_HERE.md`부터 AI에게 읽히면 됩니다. 상세 내용은 [AI 전달](AI_HANDOFF.md)을 참고하세요.
