# 사용 가이드

## 프로젝트 시작

작업 공간에서 **새 프로젝트**를 누르거나 프리셋 카드를 선택합니다. 브랜드 랜딩·대시보드·설정·스토어·팩별 대표 페이지 또는 빈 화면으로 시작할 수 있습니다. **크게 보기**로 확인한 뒤 편집할 프로젝트를 만드세요.

왼쪽은 컴포넌트·레이어·테마·자산, 가운데는 캔버스, 오른쪽은 선택한 요소의 속성입니다. 상단에서 페이지, 화면 폭, 실행 취소, 공유, 미리보기, AI 전달을 선택합니다.

## 화면 조립과 배치

1. 라이브러리에서 요소·블록·장면을 선택하거나 캔버스로 끌어 넣습니다.
2. 자동 배치는 부모의 Flex/Grid 규칙을, 자유 배치는 직접 좌표·크기·회전을 사용합니다.
3. 레이어에서 부모와 순서를 변경하고 캔버스에서 위치와 크기를 조절합니다.
4. Shift+클릭으로 여러 요소를 골라 정렬·같은 간격·그룹화를 적용합니다.
5. 자동/자유 배치 전환은 결과를 미리 본 뒤 적용합니다.

조합 블록과 장면의 제목·버튼·사진은 독립된 자식 요소입니다. 각 자식을 이동·삭제·복제하고 내용을 바꿀 수 있습니다.

## 컴포넌트 내부 편집

요소를 선택한 뒤 오른쪽 **내부 요소** 목록을 사용하거나 캔버스에서 Ctrl/⌘+클릭합니다. 내부 제목·버튼·아이콘·표 셀·SVG 도형·이미지·편집용 미디어 컨트롤을 선택합니다.

- 텍스트를 더블클릭해 입력하고 Ctrl/⌘+Enter로 확정합니다.
- 글자·색상·위치·크기·회전·방향별 여백·모서리·그림자를 조절합니다.
- 속성 옆 초기화 버튼으로 현재 화면 범위의 수정만 지웁니다.
- **이 부분의 동작 실행**으로 대화상자를 열고 열린 내용도 편집합니다.
- 긴 내부 목록은 전체 검색과 100개씩 표시를 지원합니다. 부분 수정은 컴포넌트당 최대 5,000개입니다.

문구는 공통 콘텐츠에, 외형은 선택한 화면 범위에 저장됩니다. 브라우저 기본 미디어 UI와 캔버스 내부 픽셀은 개별 DOM 부분으로 선택되지 않습니다.

## 테마와 화면 폭

**테마**에서 라이트·다크, 색상·밀도·모서리, 제목/본문 서체를 정합니다. T01~T08 팩은 색상·서체·표면·모션을 선택 적용하고 현재 페이지를 세 폭에서 비교합니다. 기본 적용은 직접 고친 내용·배치·외형을 유지합니다. 초기화 옵션은 영향 목록을 확인한 뒤 적용하세요.

기준 폭은 390·768·1440px이며 320~2560px을 직접 입력할 수도 있습니다. 모바일 기본값 위에 태블릿(768px 이상), 데스크톱(1024px 이상) 수정이 적용됩니다. 캔버스 확대 배율과 실제 viewport 폭은 별개입니다.

## 자산과 미디어

**자산** 탭에서 이미지·영상·음성·WOFF2 서체·VTT 자막을 등록하고 요소에 연결합니다. 대체 설명·출처·영상 표지도 정리하세요. 갤러리의 **항목별 편집 시작**을 누르면 사진·제목·설명·순서를 각각 바꿀 수 있습니다.

새 영상·오디오의 컨트롤은 재생·탐색·음량·속도를 실제 미디어 상태와 연결합니다. 이전 문서는 기본 컨트롤을 유지하며 **재생 컨트롤 편집 켜기**로 전환할 수 있습니다. 시간·속도 숫자는 재생 상태를 따라 갱신되므로 외형만 바꿉니다. 자막·전체 화면·코덱 지원은 브라우저에 따라 달라집니다.

편집과 PNG에서는 재생 없는 표지를 표시합니다. 내장 사진은 AI로 만든 가상 공간·제품이고 영상·음성은 직접 생성한 추상 모션·전자음입니다. [출처 안내](../THIRD_PARTY_NOTICES.md)를 참고하세요.

## 콘텐츠와 동작

챕터 탐색은 같은 페이지의 요소로 이동합니다. 여러 단계 폼에서 단계·질문·입력 종류·필수 여부를 편집합니다. 단계 복제는 연결 질문과 부분 외형도 복사하며 삭제 시 질문은 첫 단계에 보존합니다. 서식 본문은 문단·제목·목록·인용과 굵게·기울임·코드·링크를 지원합니다.

미리보기에서 폼 검증·탭·표 정렬·대화상자를 조작합니다. 폼 입력은 프로젝트에 저장하거나 서버에 제출하지 않습니다. 인증·결제·데이터 연결은 AI 구현 요구사항으로 전달하세요.

## 모션

**디자인과 효과 → 모션 세부 조절**에서 효과·시간·지연·강도·반복·속도 곡선·시작 조건·모바일 정지를 정합니다. 페이지 열기, 화면 진입, 호버/포커스, 클릭/키보드, 스크롤 진행을 지원합니다.

미리보기의 제어 막대로 전체 또는 선택 범위를 재생·정지·처음부터·한 주기 탐색합니다. 편집·PNG·움직임 감소에서는 원래 콘텐츠를 정지 상태로 보여줍니다. 단어 효과는 고정 제목·본문·인용을 대상으로 합니다.

## 단축키

| 키                    | 동작                          |
| --------------------- | ----------------------------- |
| Ctrl/⌘+Z              | 완료한 편집 실행 취소         |
| Shift+클릭            | 여러 요소 선택                |
| Ctrl/⌘+클릭           | 컴포넌트 내부 부분 선택       |
| 방향키 / Shift+방향키 | 자유 배치에서 1px / 10px 이동 |
| Alt+드래그            | 이동 스냅 해제                |
| Space+드래그          | 캔버스 이동                   |
| Esc                   | 진행 중인 조작 취소           |
| 텍스트 더블클릭       | 직접 입력                     |
| Ctrl/⌘+Enter          | 직접 입력 확정                |

입력창에서 글을 쓰는 동안에는 캔버스 단축키의 동작 범위가 제한됩니다.

## 저장과 전달

상단 자동 저장 상태를 확인하고 중요한 작업은 자산 포함 ZIP으로 백업하세요. 같은 프로젝트를 두 탭에서 바꾸면 충돌을 알리며 현재 작업을 사본으로 저장할 수 있습니다. **복구 자료**에서 미저장 작업을 다운로드하거나 사본으로 엽니다. 체크포인트는 최대 20개이며 복원도 실행 취소할 수 있습니다.

**AI에 전달**의 프롬프트 또는 ZIP을 외부 코딩 AI에 제공합니다. `START_HERE.md`부터 읽게 하고 구조·값·동작 명세를 기준으로 구현하도록 요청합니다. [전달 안내](AI_HANDOFF.md)에 파일 목록이 있습니다.

다른 기기로 옮길 때는 **자산 포함 ZIP 백업**을 사용합니다. JSON과 공유 링크에는 업로드 원본 파일이 없습니다. 공유는 발행 당시 사본이며 링크 회수·만료 기능은 없습니다.
