# 라이선스 상태

이 업로드 패키지에는 프로젝트 자체의 사용·수정·재배포 조건을 정하는 LICENSE 파일이 아직 없습니다. 저장소 소유자가 라이선스를 선택하지 않았으므로 MIT, Apache-2.0 등 특정 조건을 임의로 적용하지 않았습니다.

소스 공개 여부와 프로젝트의 라이선스 지정은 별도로 관리합니다. README나 소개에서 현재 프로젝트를 특정 오픈소스 라이선스로 배포한다고 표시하지 않습니다.

소유자가 조건을 정하면 루트에 해당 LICENSE를 추가하고 README 및 이 문서를 갱신하세요. 패키지 의존성과 외부 자산의 조건은 [외부 의존성·자산 안내](THIRD_PARTY.md)를 별도로 확인합니다.
