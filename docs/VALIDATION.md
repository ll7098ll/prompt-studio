기준일: 2026-10-07. 이 문서는 문서 정리·GitHub 패키징 작업에서 직접 실행한 범위만 기록합니다.

## 소스 기준

동일 작업 공간에서 **테마와 컴포넌트 확장 계획** 채팅이 추가 모션을 수정 중이므로, 이번 업로드본은 앱 소스 커밋 `d27c88cc0486882109c74be58ed95f7ed3743c9b`를 기준으로 합니다. 새 README·문서·화면·GitHub 양식·패키징 도구와 생성 폴더 제외 설정을 합쳤습니다. 작업 중인 앱 코드와 테스트는 원본 폴더에 그대로 보존했습니다.

현재 working tree 전체와 이 업로드본의 앱 기능은 다를 수 있습니다. 모션 설명의 기존 CSS 12종·추가 4종은 위 커밋의 지원 범위입니다. 이후 기능을 포함하려면 해당 변경의 검증이 끝난 뒤 `npm run package:github -- --name prompt-studio-v2`로 새 사본을 만듭니다.
