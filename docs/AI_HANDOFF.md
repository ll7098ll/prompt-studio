# AI에 설계 전달하기

## 권장 순서

1. 문구·이미지 주소·배치를 실제 의도에 맞게 수정합니다.
2. 390·768·1440px 및 필요한 추가 폭에서 넘침과 잘림을 확인합니다.
3. 사용할 컴포넌트의 상태와 기본 동작을 확인합니다.
4. **AI에 전달**에서 ZIP을 다운로드합니다.
5. 외부 코딩 AI에 ZIP을 첨부하고 아래처럼 요청합니다.

> START_HERE.md와 PROMPT.md를 먼저 읽고 ui-spec.json의 모든 페이지를 구현해 주세요. 구조·문구·실제 테마 값·반응형 규칙을 유지하고, component-specs.json의 상태와 키보드 동작을 반영해 주세요. 이미지와 명세를 비교하고, 연결되지 않은 데이터·인증·결제는 미정 사항으로 따로 설명해 주세요.

이미 작업 중인 저장소가 있다면 대상 프레임워크, 프로젝트 경로, 데이터 API 요구사항을 추가로 알려주세요. 앱이 생성하는 기본 프롬프트는 React와 TypeScript를 기준으로 하며 기존 저장소의 규칙을 먼저 확인하도록 안내합니다.

## ZIP 파일

| 파일                   | 역할                                             |
| ---------------------- | ------------------------------------------------ |
| `START_HERE.md`        | 읽는 순서와 파일별 설명                          |
| `PROMPT.md`            | 구현 지시와 설계 데이터                          |
| `project.json`         | 스튜디오에서 다시 열 수 있는 원본                |
| `ui-spec.json`         | 페이지·노드·화면별 해석된 레이아웃·컴포넌트 명세 |
| `theme.json`           | 현재 모드와 라이트·다크 실제 값                  |
| `theme.css`            | 현재 모드의 CSS 변수                             |
| `theme.tokens.json`    | DTCG 2025.10 형식의 디자인 토큰                  |
| `component-specs.json` | 사용한 컴포넌트의 속성·상태·키보드·동작          |
| `reference.css`        | 공통 렌더러의 참고 스타일                        |
| `screenshots/`         | 페이지별 390·768·1440px 기준 이미지              |
| `ACCEPTANCE.md`        | 결과 확인 항목                                   |
| `manifest.json`        | 버전·revision·이미지 목록·파일별 SHA-256         |

현재 handoff format 버전은 1, 프로젝트 schemaVersion은 2, rendererVersion은 2.1.0입니다. 서로 다른 목적의 버전이므로 하나로 취급하지 않습니다.

`resolvedLayouts`의 gap·padding·margin은 밀도가 이미 적용된 값입니다. 기본 props와 기본 인터랙션 상태를 기준으로 캡처하므로 미리보기에서 잠깐 열어 둔 팝업이나 선택 상태가 모두 저장된다고 가정하지 마세요.

## 결과 검토

- 모든 페이지와 children 순서, 중첩 구조가 유지됐는지 확인합니다.
- 테마의 실제 값과 라이트·다크 대응을 비교합니다.
- 기준 폭에서 원본 이미지와 구현 결과를 나란히 확인합니다.
- 키보드로 탭·팝업·메뉴·입력을 조작합니다.
- 샘플 응답·제출을 실제 서버 연동으로 오해하지 않도록 연결 범위를 확인합니다.

외부 AI의 독립적인 화면 재현 평가는 아직 수행하지 않았습니다. 정확한 명세와 이미지를 제공하지만 결과의 일치율을 보장하는 점수는 없습니다.

## 제한과 대안

외부 이미지 URL과 글꼴은 ZIP에 자동 포장하지 않습니다. 이미지 서버가 캡처 접근을 허용하지 않으면 PNG 생성이 실패할 수 있습니다. 이 경우 JSON·프롬프트를 별도로 전달하고 이미지 사용 조건과 접근 방식을 정리하세요.

파일을 받지 못하는 AI에는 프롬프트를 복사해 전달할 수 있습니다. 큰 설계는 모델의 입력 길이 제한을 확인하고 원본을 보존한 상태에서 작업 범위를 나눕니다.
