# 구현·검증 상태

기준일: 2026-10-06. 현재 기준은 **로그인 없는 공개 서비스**다. 인증·계정·클라우드 프로젝트 DB는 제외했다. 계획의 확장 목표와 실제 기능을 구분한다. 최신 드래그·디자인 확장을 기존 Sites 프로젝트에 반영한다. 배포와 검사 결과는 아래 최신 기록을 따른다.

## 2026-10-07 디자인·미디어 확장 진행

모션 세부 설정과 미리보기 재생 제어를 추가했다. 기존 12효과에 새 4효과(단어·마스크·스크롤 깊이·스크롤 확대)를 더했고, 시간·지연·강도·반복·속도 곡선·시작 조건·모바일 정지를 저장한다. 선택/전체 재생·정지·처음/진행 탐색, 실제 화면 진입과 스크롤, 내부 스타일 보존을 검증한다. 신규 모션 12후보 전체가 완료된 것은 아니며 이번 구현과 검사 결과는 실행 기록의 최신 항목을 따른다.

영상·오디오의 편집용 컨트롤도 추가했다. 재생 버튼·아이콘, 진행 막대의 배경/채움/손잡이, 시간 표시, 음량·속도와 영상의 자막·전체 화면 버튼을 내부 역할로 선택해 각각 조절한다. 이전 문서는 기본 재생기를 보존하고 사용자가 전환할 때만 새 컨트롤을 사용한다. 시간·속도 숫자는 외형을 수정할 수 있지만 실제 재생 상태와 연결을 유지한다. 재생과 선택·반응형·복원 검사 결과는 아래 실행 기록의 최신 항목을 따른다.

신규 미디어 5종, 자산 업로드/교체/ZIP 복원, 제목·본문 사용자 서체, 갤러리 항목 편집, v5 문서와 이전 원본 보존을 구현했다. 내부 SVG·이미지·열린 대화상자 편집, 실제 값과 속성 출처·개별 초기화, 방향별 여백·모서리·배치, T01~T08 팩의 선택 적용·비교에 이어 챕터 탐색·단계 폼·서식 본문을 추가했다. 여기에 독립 자식으로 이루어진 장면 12종과 첫 8개 팩의 대표 페이지를 추가해 총 정의 225개, 삽입 가능 224개, 시작 프리셋 25개다. 내부 목록의 앞 500개 제한을 없애고 전체 검색/100개씩 표시하며 부분 수정 5,000개를 저장할 수 있다. 후속 팩·고급 편집은 계속 구현 중이며 전체 계획을 완료한 것으로 표시하지 않는다. 최종 재검사·입력 성능·배포와 다음 작업은 [실행 기록](EXPANSION_EXECUTION.md)을 따른다.

## 후속 과제

첫 버전은 등록된 컴포넌트로 웹 설계를 만들고 AI에 전달하는 도구다. 앱 내부 AI 생성·실행, 계정 동기화, 실시간 협업, 회수 가능한 공유, 임의 코드 실행은 제공하지 않는다.

다음은 계획에 있었지만 아직 구현·검증되지 않았다.

- 큰 문서의 WebKit 입력 반영 반복 측정 편차 원인 확인. 10월 6일 실행에서는 p95 100ms 미만 기준을 통과했다.
- 실제 외부 AI의 독립 재현 평가와 수정 프롬프트 자동 생성.
- v1 자동 변환과 알 수 없는 미래 컴포넌트 부분 복원. 현재는 명시적으로 가져오기를 거절한다.
- 공통 컴포넌트 인스턴스, 테마 라이브러리, 사용자 폰트·이미지 업로드와 ZIP 자산 포장.
- 고급 표 행·열 구조 편집·추가 차트 종류, 공통 인스턴스와 테마 비교. 표 셀 문구·스타일, 그룹과 기본 차트·달력·팝업·알림은 구현했다.
- macOS/iOS Safari·Android 실기기 및 실제 한국어 IME 후보 입력 검증. 현재의 한국어 입력 자동 검사를 OS 입력기 검증으로 간주하지 않는다.
- 신규 사용자 관찰 기반 사용성 평가와 장기 운영·장애 복구 실측.

외부 이미지는 원격 URL로 유지되며 캡처 접근이 허용되어야 한다. 긴 페이지·큰 이미지·장시간 ZIP 작업에는 제한이 있다. 목적지가 없는 메뉴와 버튼은 프롬프트에서 연결 요구사항이 미정임을 알린다.
